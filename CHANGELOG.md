# Changelog

## 0.1.1

- Bound desktop and browser text conversions and file reads without truncating input.
- Preserve existing text when a selected file is oversized or unreadable.
- Pin Pages actions and Python build tools; restrict deployment permissions to the deploy job.

## 0.1.0

- Initial ByteNoise desktop app.
- Added static GitHub Pages web app.
- Added compatibility decoding for older direct-offset ByteNoise text.
- Added GitHub Actions for linting, unit tests, package builds, and Pages deploys.
