What it does

ByteNoise turns UTF-8 text into uncommon Unicode characters and can reverse it back. Decoding ignores pasted whitespace and supports the older direct-offset format.

What it is not

This is obfuscation, not cryptography. Do not use it for passwords, tokens, keys, private messages, or regulated data.
